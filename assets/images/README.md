# Photos des packagings Pétote

Quatre visuels photoréalistes générés avec ImageGen pour cette étude de cas.
Ils sont intégrés localement dans l'application, sans appel réseau.

- chips_nature.png : Sel marin, 125 g.
- chips_maroilles.png : Andouillette & Maroilles, 150 g.
- chips_gaufre.png : Gaufre lilloise, 150 g.
- chips_cambrai.png : Bêtise de Cambrai, 150 g.

Format : PNG 1024 × 1536 px, portrait, fond ivoire opaque.
Ce sont des propositions graphiques pour le devoir, pas des photographies de produits commercialisés.
Les consignes de génération sont documentées dans docs/IMAGES.md.
